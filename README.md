# Task Management System

Frontend of the Task Management System built with Angular.

## Features

* User Registration and Login
* JWT Authentication
* User and Admin Roles
* Task Create, Update and Delete
* Task Search and Filtering
* Admin User Management
* Authentication Guard
* HTTP Interceptor
* Form Validation

## Technologies

* Angular
* TypeScript
* HTML
* CSS

## Run the Project

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
ng serve
```

Open:

```text
http://localhost:4200/
```

## Backend

This frontend uses a separate ASP.NET Core Web API backend.
